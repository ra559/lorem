# Lorem Ipsum Generator

A simple, lightweight, browser-based Lorem Ipsum generator built with HTML5, CSS3, and vanilla JavaScript.

Generate placeholder content for web development, UI prototyping, document layouts, and design projects. Choose the amount of content, select an output format, and copy the generated text.

## Features

### Content Generation

Generate Lorem Ipsum content using three different modes:

- **Words** — Generate a specified number of random words.
- **Sentences** — Generate complete sentences with randomized lengths.
- **Paragraphs** — Generate paragraphs containing multiple sentences.

### Output Formats

Choose from three output formats:

| Format | Description | Example |
|---|---|---|
| Plain Text | Standard paragraphs separated by blank lines | `Lorem ipsum dolor sit amet.` |
| Markdown | Paragraphs formatted as Markdown blockquotes | `> Lorem ipsum dolor sit amet.` |
| HTML | Paragraphs wrapped in HTML `<p>` elements | `<p>Lorem ipsum dolor sit amet.</p>` |

### Additional Features

- Adjustable generation quantity (1–100).
- One-click content generation.
- Copy generated content to clipboard.
- Light and dark themes.
- Theme preference saved using browser local storage.
- Responsive interface for desktop and mobile devices.
- Automatically generates initial content when the application loads.

## Getting Started

### Requirements

- A modern web browser.
- Internet connection to load Bulma CSS and Google Fonts.

No backend, database, package manager, or JavaScript build tools are required.

### Installation

Clone the repository:

```bash
git clone https://github.com/ra559/lorem.git
```

Navigate into the project directory:

```bash
cd lorem
```

Open the application:

```bash
xdg-open index.html
```

Alternatively, open `index.html` directly in your browser.

### Running a Local Web Server

For local development, use Python's built-in HTTP server:

```bash
python3 -m http.server 8000
```

Navigate to:

```text
http://localhost:8000
```

## Usage

1. Select the content generation mode: Words, Sentences, or Paragraphs.
2. Specify the desired quantity (between 1 and 100).
3. Select an output format: Text, Markdown, or HTML.
4. Click **Generate**.
5. Click **Copy** to copy the generated content to your clipboard.

Use the theme button to switch between light and dark appearances.

## How It Works

The generator uses a predefined collection of Lorem Ipsum words.

JavaScript randomly selects words from this collection to construct the requested content.

- Words are generated by randomly selecting individual words.
- Sentences contain a randomized number of words, with capitalization and punctuation.
- Paragraphs contain multiple generated sentences.
- The selected output formatter converts the generated content into plain text, Markdown blockquotes, or HTML paragraphs.

All generation takes place locally in the browser.

## Privacy

Lorem Ipsum Generator does not require an account, backend, or database.

Content generation happens entirely in the browser. The application stores only the selected theme preference in browser local storage.
